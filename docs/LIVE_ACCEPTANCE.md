## 可执行验收工具

在项目根目录且服务已运行时执行，统一使用本地config.toml：

```powershell
# 默认只读，不建数据集、不发下载、不写历史库
.venv\Scripts\python.exe -X utf8 tools/live_acceptance.py
# 自选期货与股指期权，只读检查每个样本
.venv\Scripts\python.exe -X utf8 tools/live_acceptance.py --codes cu2610.SF HO2609-C-2500.IF
# 显式下载：先选择已结束的短交易区间
.venv\Scripts\python.exe -X utf8 tools/live_acceptance.py --download --start 2026-09-08 --end 2026-09-14
# 历史链路恢复后，验收单个交易日的期货分钟线
.venv\Scripts\python.exe -X utf8 tools/live_acceptance.py --download --codes cu2610.SF --period 1m --start 2026-09-14 --end 2026-09-14
```

默认样本仍为`000300.SH`、`000001.SZ`、`510300.SH`，周期`1d`。`--codes`可选择最多10个本项目支持的证券/合约，组合代码含空格时用引号包裹。`--period`支持`1d/1m/5m`；日线最多15个自然日，分钟线只接受一个交易日，均不允许未来日期。行业概念使用具体成员代码，不使用板块名称作为证券代码。

未加`--download`时，逐样本执行只读日线诊断，报告明确`diagnostic_period=1d`，不代表已验证所选分钟周期；`diagnostics`按代码保存各样本结果。显式下载时，有活动任务则拒绝继续；新建不定时小样本数据集，执行两次相同区间回补，再核对指定周期的SDK分页、数据库、CSV BOM、Parquet、夜盘交易日及不复权口径。不会自动取消原任务、开关调度或删除数据。

报告及导出写入 `output/live-acceptance/<时间>/`，失败保留阶段、样本、周期和任务ID，便于从任务页定位。`partial`不能算完整通过；分钟内覆盖尚待核验时，即使数据库与文件一致，报告也保持`partial`。每个任务等待超过300秒则结束验收等待，不代表撤销终端请求。工具已在隔离数据库完成默认三证券和自选期货/期权的三个周期测试，尚未使用真实行情完成下载验收。

5. 对同范围重复回补，比较数据库复合键行数和修订值；验证可获得复权因子。无原生因子能力时保持说明，不伪造。
