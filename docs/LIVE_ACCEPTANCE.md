## 可执行验收工具

在项目根目录且服务已运行时执行，统一使用本地config.toml：

```powershell
# 默认只读，不建数据集、不发下载、不写历史库
.venv\Scripts\python.exe -X utf8 tools/live_acceptance.py
# 显式下载：先选择已结束的短交易区间
.venv\Scripts\python.exe -X utf8 tools/live_acceptance.py --download --start 2026-09-08 --end 2026-09-14
```

`--download` 固定选择 `000300.SH`、`000001.SZ`、`510300.SH`，仅日线、最多15个自然日，不允许未来日期。检查有活动任务时拒绝继续；新建不定时小样本数据集，执行两次相同区间回补，再核对SDK分页、数据库、CSV BOM、Parquet和不复权口径。不会自动取消原任务、开关调度或删除数据。

报告及导出写入 `output/live-acceptance/<时间>/`，失败保留阶段和任务ID，便于从任务页定位。`partial` 不能算完整通过；每个任务等待超过300秒则结束验收等待，不代表撤销终端请求。工具已在隔离数据库完成全链路测试，尚未使用真实行情完成下载验收。
