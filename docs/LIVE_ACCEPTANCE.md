## 可执行验收工具

在项目根目录且服务已运行时执行，统一使用本地config.toml：

```powershell
# 默认只读，不建数据集、不发下载、不写历史库
.venv\Scripts\python.exe -X utf8 tools/live_acceptance.py
# 显式下载：先选择已结束的短交易区间
.venv\Scripts\python.exe -X utf8 tools/live_acceptance.py --download --start 2026-09-08 --end 2026-09-14
```

`--download` 固定选择 `000300.SH`、`000001.SZ`、`510300.SH`，仅日线、最多15个自然日，不允许未来日期。检查有活动任务时拒绝继续；新建不定时小样本数据集，执行两次相同区间回补，再核对SDK分页、数据库、CSV BOM、Parquet和不复权口径。不会自动取消原任务、开关调度或删除数据。

报告及导出写入 `output/live-acceptance/<时间>/`，失败保留阶段和任务ID，便于从任务页定位。`partial` 不能算完整通过；每个任务等待超过300秒则结束验收等待，不代表撤销终端请求。工具已在隔离数据库完成全链路测试，尚未使用真实行情完成下载验收。

## 接入条件

使用已授权的现有 PostgreSQL 14+实例，配置专用登录与pfor_qmt schema；不复用其他应用配置。退出大QMT后通过设置页准备PFOR_MARKET，启动完成导入，再退出启用并重启登录。检查cfquant原模型的名称、启用状态及配置保持不变。

## 小样本顺序

1. 选择用户终端有权限的一个指数、一只A股、一只ETF，例如000300.SH、000001.SZ、510300.SH；先读基本资料和快照，核对代码、价格、时间与终端。
2. 分别建立tick订阅、全市场订阅，核对首包和后续推送；退订后确认无继续事件。断开重连终端，确认网页状态和重订阅。
3. 下载最近五个交易日日线，读回不复权OHLC、原始成交量/额；核对终端单位和上海交易时间，不能只看下载返回值。
4. 下载一日1m和5m；核对开收盘边界、集合竞价、停牌、时间标签及行数。确认终端约定后才能将分钟覆盖由待核验升级为完整。
5. 对同范围重复回补，比较数据库复合键行数和修订值；验证可获得复权因子。无原生因子能力时保持说明，不伪造。
6. 建立指数与QMT板块映射，保存当前成分快照并创建数据集；刷新指数快照不应自动修改原数据集或已排队任务。
7. 验证中断/重启检查点、运行中取消、失败重试；至少运行一个17:00调度周期，确认同日不重复建任务。
8. QMT退出后，验证历史查询、分页、CSV/Parquet导出和口径JSON仍正常。用Decimal或等价精确方式逐行比较API、数据库、文件。

完成以上小样本后，再扩大到一年日线、90天分钟线及更多选定证券。实机报告应记录终端版本、行情权限、样本、时间范围、通过/失败/未验证，且不记录账户密钥或数据库密码。
