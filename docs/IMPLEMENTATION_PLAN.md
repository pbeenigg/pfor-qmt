## 已确认范围

基于 cfquant 提交 `5baa4daf8dab01fb415afdd45a72cd254cea042f` 派生，仅提供行情。

Web 工作台、Python SDK、API Key 与可选网页登录。明确排除交易、多终端、高级模式、LITE、Level2、千档、财务、公式、权重和历史成分、自动登录、在线更新。

## 行为约定

- 首次任务默认日线一年、分钟90天，范围可修改，不自动下载全市场。
- 按指数创建的数据集固定创建时成分，手动刷新成员。
- 按数据集启用交易日17:00更新，Asia/Shanghai；回读最近5个交易日，恢复时补执行到期任务。
- 单源单补数任务；分证券/时间段检查点，网络失败至多重试3次；取消只停止后续分段。
- 下载、读缓存、校验、事务入库分别有明确状态；空数据和覆盖缺口不判完整成功。
- 历史库无需QMT在线；实时Tick不持续落库；导出采用不复权口径并带说明文件。
- 本机HTTP默认8766，独立命名管道和QMT模型。数据库使用用户指定实例，凭据仅在本地配置。

1. 规范与来源：AGENTS、许可证、来源文件哈希、兼容矩阵、独立Git基线。
2. 行情桥与SDK：上游协议对比、交易拒绝、生命周期、首包与退订、旧下载接口全证券回退。
3. PostgreSQL与任务：迁移、去重和修订、精度、恢复、取消重试、调度去重和导出一致性。
4. Web：查询、图表、任务、设置、桌面与移动浏览器验证。
5. 部署与实机：隔离模型、不覆盖原配置；用户指定QMT和数据库的小样本对比；逐项报告通过、失败和未验证，行情连接恢复前不扩大回补。
6. 打包：包含许可与静态资源，排除凭据、运行数据、日志和测试导出。
