# Web 控制台交互与分析能力整改计划

## 已确认目标

分组侧栏、独立页面、浅色专业工作台，同时完善数据分析与运行统计。保留原生HTML/CSS/JavaScript、本地ECharts及Lucide，编辑只针对管理配置，采集记录只读，不新增技术指标或交易。

## 页面职责

- 数据查询：证券目录、实时行情、历史行情、指数成分、行业概念。
- 期货资料：交易日历、主力连续映射、仓单日报、成交持仓排名、结算参数、交易周报，分别独立页面。
- 采集管理：数据集、采集执行、任务记录、导出记录、自动维护。
- 质量运维：运行概览、数据质量、任务日志、服务日志。
- 系统设置：Tushare账号、QMT连接与部署、数据库、访问与服务配置。

目录同步移至采集执行，数据集移出历史页。任务详情独立页，分概览/质量/事件/关联任务。旧market/futures/operations/settings地址兼容；浏览器前进后退恢复上下文。记录侧边详情，手机全屏。

## 查询编辑与执行

统一已应用查询与草稿，多选/全选/跨页、上海快捷日期、50/100/200分页、白名单排序、总数、列显隐。命名查询和列偏好仅存浏览器，不存凭据；切换来源取消旧请求结果。图表导出使用已应用范围。

编辑面板支持就地校验、保存取消、未保存离开提醒。数据集支持新建/编辑/复制，来源不可变，快照成员须显式刷新或复制为手工集合。维护直接新建或从任务创建，默认停用，可编辑/复制/启停/执行一次，范围编辑先停用并预览差异。既有排队任务保持固定快照。执行确认账号/来源/范围/权限，批量取消重试逐项反馈，补数沿用已有预览。

## 图表统计与接口

新增history/summary、history/chart、futures/summary、operations/summary和SDK方法。统计全查询范围，共用筛选与快照标识，返回口径、实际范围、评估时间及截断标志。图表默认最新1000条，单窗口最多5000，可前后加载，不合成K线。

K线联动量仓；日历开市/休市/未知；映射时间轴保留未知；仓单分原始维度与单位，不重复合计汇总和明细；排名仅所选范围；结算保留费率原值；周报不累计存量/累计值/百分比。最多六条可比序列。运行统计涵盖状态/每日趋势/积压/核验/新鲜度并可下钻，无依据不算完整率。

新增数据集更新、维护预览、执行一次，配置更新校验版本；迁移仅加配置版本和必要索引，不改行情、不新建任务或统计库。旧接口默认兼容。

## 实施验收

顺序：导航视觉、查询编辑、图表统计、全链路回归。浏览器覆盖1440/1024/768/390px、键盘焦点、多选日期、详情、无页面横溢及图表非空。业务链路覆盖目录到数据集、编辑、预览执行、任务质量日志、查询导出和维护启停。

验证超过300/5000条、跨页汇总、Decimal/NULL、夜盘周月、混合单位、仓单重复、不完整排名、并发修改、重复提交、断线权限、取消重试；完整现有回归及构建资源检查。实机小范围，分别报告通过/失败/未验证。保留用户改动，不修改cfquant或QMT模型。
