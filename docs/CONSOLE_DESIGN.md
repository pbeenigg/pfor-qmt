# 控制台设计规范

采用ui-ux-pro-max密集数据工作台方向：分组侧栏、每页单一主流程、白灰背景、绿色主操作，蓝色运行、琥珀待处理、红色故障，状态均有文字。

系统中文字体，正文与表格13至14px、标题22px、等宽数字；控件40px，手机44px；间距8/12/16/24px，圆角4至8px。页面不做浮动或嵌套卡片，宽表仅局部滚动，侧栏可滚动、小屏折叠。

查询草稿与已应用条件分离，主操作明确。新增编辑用面板、就地校验、保存取消与离开提醒。详情保留精度/NULL/单位，关闭焦点返回。图表本地ECharts，显示来源和实际窗口；不同口径不混用。

验收1440/1024/768/390px、键盘焦点、4.5:1正文对比度、减少动画偏好、图表非空与无页面横溢。
