# 控制台列表与筛选检查

## 历史汇总与资料名称（2026-09-20）

- 历史行情查询结果上方改为默认展开的“范围汇总”表，不再用连续大块指标卡堆叠。按合约/周期分组，每页5组，可切换5/10/20组、搜索名称/代码、前后翻页；点击行内图表按钮只切换图表对象，原查询范围不变。汇总显示记录数、最高/最低、成交量、成交额和末条持仓，空值显示未提供。
- 汇总表与K线、明细表独立加载；返回历史页恢复汇总页、搜索和图表窗口。明细仍使用原有分页，汇总不以当前明细页冒充全范围统计。
- 主力连续映射和结算参数的统计、图表图例、坐标轴、tooltip、资料表及详情优先显示当前数据源证券目录中的名称，代码作为次要标识。目录没有名称时显示“名称未收录”，不从代码猜测。
- 映射图表显示“主力/连续名称 → 对应月份合约名称”，结算参数按合约名称分组；同名不同代码保留代码辅助区分。查询、导出和数据库原始字段不改变。

历史汇总表显示来源、时间范围和单位说明；名称未收录时明确标记，不用代码片段拼接伪名称。

## 期货资料明细筛选（2026-09-20）

- 仓单日报新增仓库、单位多选，成交持仓排名新增会员多选。展开“明细筛选”读取当前对象和日期范围内的实际入库选项，支持搜索、全选及清空。
- 名称原值保留，包括逗号、空字符串及NULL；NULL明确标为“未提供”。选项超过1000个时要求缩小范围，不静默截断。
- 表格、全范围统计、图表和CSV/Parquet导出使用同一筛选。筛选仅影响查询结果，不改写行情资料，不把仓单汇总行和明细合计，不改变单位。
- 修改日期或对象后，已有明细选择保留；刷新选项时，仍选中但当前范围无记录的值会明确标注，不因为刷新而自动扩大查询。页面返回和命名查询恢复保留明细条件。
- 按明细筛选后点击采集，会先确认按所选交易所、品种或合约及日期采集完整资料。会员、仓库和单位不传为上游采集过滤条件；取消确认不创建任务。维护范围遵循相同边界。

新增选项接口只读PostgreSQL；没有引入新数据源、存储表或依赖。实际写入及双格式导出使用隔离测试，实机仅核对已有记录和取消确认。

## 查询上下文与任务定位（2026-09-20）

- 排序与每页条数只调整已查询结果，不提交尚未应用的条件。任务/导出以及各类期货资料分别保存展示设置；返回列表恢复页码、日期快捷项和筛选草稿。
- 期货资料重置保留当前页面类型及有效默认日期。交易所选项加载后，仅恢复依赖的品种与主力代码，不覆盖用户刚修改的对象类型、日期或合约。
- 任务详情的分块页增加对象/周期/错误搜索、执行状态和数据质量多选，支持50/100/200条分页及总数；直接显示对象、请求区间、入库或核验行数和记录时间。重试标记注明“可自动重试”，不与人工重试入口混淆。
- 详情事件可按说明、错误码、级别和时间筛选，支持快捷日期。全局任务日志支持消息搜索及至少8位任务ID前缀。任务详情可刷新，并返回进入详情前的页面。
- 同一查询范围内，表格翻页复用全范围统计，保留图表窗口或指标选择。图表请求失败单独提示，保留已成功读取的表格；切换来源清理旧单位、时间窗及分页状态。
- 刷新列表同步已选任务的最新状态，避免批量操作仍按旧状态计算。数据库恢复后，运行概览可通过重新查询恢复统计。

本轮为查询与交互修改，schema仍为10，不修改采集范围、任务状态、行情数据或上游授权。

## 回收站与后续检查（2026-09-20）

- 数据集、维护计划、已结束任务和导出记录增加“移入回收站”“恢复记录”，列表的“记录范围”可选当前、回收站或全部。删除和恢复均显示确认内容；取消不写入。
- 配置移入回收站时停用自动更新，恢复后仍停用。活动任务不能回收；有关联活动任务的配置不能回收；被未删除维护计划引用的数据集必须先处理依赖。配置操作校验版本，并由数据库约束保护并发入队。
- 回收只改变列表可见性，保留行情、资料、导出文件、任务分块、事件与父子关系。回收站任务只读，恢复前不能重试、补数或派生维护；质量问题仍在质量页追踪，不因回收而视为解决。
- 账号列表增加名称/ID/端点和启停筛选；账号删除须确认，含回收站在内的配置引用仍受保护。已保存指数列表增加本地名称/代码/板块搜索，不修改快照。
- 已保存查询增加删除、覆盖确认和取消入口；重新聚焦不会丢失选中查询。不同来源和页面的浏览器偏好保持隔离。
- 删除末页记录后返回有数据的页码，零结果显示0项；数据集不再把“筛选未匹配”描述成整个来源没有数据。配置、质量和日志列表沿用统一查询顺序保护，避免后台刷新覆盖手动查询。

本轮不提供清空行情库、清除未解决质量证据、永久清理导出文件或一键清空回收站。回收站无需另建数据体系，使用schema10的deleted_at字段；恢复不自动创建采集任务。

## 统一交互

- 有“查询”按钮的列表，修改条件是草稿；查询成功后才替换结果范围。翻页、自动刷新和全选匹配结果沿用已应用条件。请求失败显示原因，保留上次成功结果。
- 合约选择增加类型筛选，分页加载或失败期间禁用无效翻页操作；全选不会静默截断，不自动把主力代码转换为月份合约。
- 列显隐保留首列标识和操作列；列结构变化不会错用旧索引偏好，空结果提示不随数据列隐藏。损坏的浏览器偏好按默认值恢复。
- 表内操作使用固定尺寸图标和名称提示；窄屏两列排列。宽表在自身区域滚动，长原因和范围换行，页面本身不横向溢出。
- 任务的来源、账号ID、成员、周期、日期取自固定任务记录；关联数据集/维护名称及账号显示名取自当前配置，重命名不会修改任务执行范围。旧记录缺少名称或日期时明确显示未记录。
