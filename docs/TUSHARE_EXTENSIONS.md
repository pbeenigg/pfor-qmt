# Tushare 期货扩展

## 已确认范围

2026-09-18：账户2000积分；权限以各接口实际响应为准。

- 交易日历：独立同步开市/休市日及前交易日，按交易所查询、分页、导出。
- 周/月线：上游fut_weekly_monthly，6000行上限；共用bars表，金额万元转元，保留周期标签与计算截至日，未结束周期以not_published标记等待周期结束。
- 分钟：具体月份合约1/5/15/30/60分钟，8000行上限，独立权限；按原始时间保存，未知交易日为空。
- 主力映射：独立同步、查询与导出，选择映射后的月份合约查询历史，不拼接连续分钟。
- 仓单：fut_wsr，1000行上限，按产品及仓库明细保存，保留原始单位。
- 成交持仓排名：fut_holding，2000行上限；产品或具体合约，保留会员、成交量、多空持仓及其变化和NULL；INE使用SHFE入口。
- Tick：官方无API，单独CSV交付。本期仅显示不可用状态；未收到实际文件前不定义猜测性导入协议。

## 实施与验收

1. 扩展数据周期和版本化迁移，QMT接口范围不变；旧数据不改写。
2. 资料任务仍用jobs/download队列、固定账号及端点；资料、coverage和检查点同事务提交。保留取消、重启恢复、网络最多三次重试；截断和空响应不算成功。
3. 查询仅依赖数据库；统一CSV/Parquet后台导出，附单位、字段和时间口径。新增资料页的类型、交易所、产品/合约选择器，避免手输代码。
4. 隔离数据库验证迁移、精度、重复采集、截至日更新、限额拆分、失败恢复和QMT兼容；浏览器覆盖桌面、手机。
5. 业务库备份后迁移，真实账号仅做已选小样本；报告权限拒绝与未验证项目，不代购权限。

## 使用入口与当前状态

工作台先选择Tushare来源和采集账号。在“期货资料”选择资料类型、交易所、产品或月份合约及日期，点击“同步资料”；任务结束后回到资料页查询，CSV/Parquet按钮进入统一导出队列。主力映射结果的月份合约可进入历史库，分钟仍需单独授权。

周/月线在“历史库”的数据集周期中选择，再发起历史回补；查询也可选择周线或月线。新建Tushare数据集默认19:00更新，可配置并显式启用。资料同步目前为手动任务，不自动开启额外定时采集。

schema5已部署，239项完整回归通过；六所日历、豆一主力映射、豆一与沪铜仓单、豆一2611排名及周/月线实测入库，数据库/SDK/CSV/Parquet一致。沪铜仓单同时包含铜与铜(BC)，名称和原始单位分别保留，不直接合计。周/月当期尚未结束显示待核验；INE原油排名样本空、分钟权限拒绝、Tick无API均不冒充通过。完整结果见[验证记录](VERIFICATION.md)。
