## 接入顺序

1. 期货与期权：六家期货交易所、沪深期权目录；保留大小写、组合符号和市场后缀，区分期货、期权与连续/组合合约。新增批量合约资料，保存原始详情及可获得的标的、到期日、行权价、乘数和价格步长。
2. 其余证券：股票扩展到终端A/B股目录；指数保留；场内基金覆盖基金目录，ETF为子类；债券包含终端债券目录中的可转债。同步当前目录，不自动回补全市场K线。
3. 行业概念：保存QMT分类树路径和当前成员快照；独立搜索页面、查看成员、从快照创建数据集、显式刷新成员。不得由名称猜测行业归属或给板块编造证券代码。
4. 行情与历史：七类中可报价的证券接入现有查询、订阅、历史查询、下载和导出；板块使用成员证券。补持仓量、结算价和交易日，日历按实际市场读取，期货/期权不请求股票复权因子。

## 验收证据

- 隔离测试：合约编码经过SDK、hub、桥、HTTP、数据库和文件不变；交易仍拒绝；Python3.6兼容；数据库迁移与旧ETF接口兼容。
- 数据：只保存终端字段，缺失保留空值；夜盘时间不移动，交易日未提供则待核验。重复下载、分页、CSV/Parquet精度、取消恢复和市场日历调度回归。
- 网页：全部类别和交易所筛选、复选/单选、合约详情、板块成员及数据集；桌面/手机/平板和键盘流程检查。
- 实机：核对新桥版本；期货、期权小样本资料与行情；七类目录数量、分类、名称与API/数据库一致。历史下载需单独证明，目录存在或行情桥连接不算历史成功。
